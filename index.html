Game Watching Prioritizer

A private NFL fantasy viewing-priority tool, currently under development for two users: the developer and one friend.

Purpose

The application identifies which NFL games contain the greatest number of players tracked across a user's fantasy football teams. It groups games into viewing windows and highlights up to four games to prioritise in each window.

How it works

The planned integration uses authorised, read-only access to Yahoo Fantasy Football team and weekly roster data, including player identifiers, names, positions and NFL-team affiliations.

Both starters and bench players are included. Kickers and team defences are excluded. Players appearing on multiple fantasy teams are counted once when ranking games.

Players are matched to NFL fixtures to produce a private viewing-priority report.

Access and data use

The application is intended to run locally on a user's computer. It is not available for public registration or download. Each user will authorise access to their own Yahoo account.

The application will not modify fantasy lineups, make transactions, or publish users' rosters or reports. No Yahoo account data is collected through this website.

Project status

Development and testing are in progress. Yahoo Fantasy Sports API access is being requested.
